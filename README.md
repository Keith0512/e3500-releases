繁體中文 Android 藍牙露營燈控制 App，支援 Android 6.0 以上。

## 1.1.0 更新內容

- 燈具群組：全部或依序開關，支援間隔與反向關燈。
- 首頁直接連線與開關燈，提供「閃一下辨識」。
- 日間、夜間與自動營地場景，燈串依實際回報顯示狀態。
- 按住再滑動調整亮度、色溫，改善頁面捲動與字級。

## 安裝與更新

1. 從 Releases 下載 APK，開啟並依 Android 指示允許安裝。
2. 1.0.7 起，可在首頁「軟體更新」檢查、下載並安裝新版。
3. App 每天在開啟時檢查一次，可在更新視窗關閉自動檢查。
4. 內建更新會驗證檔案與簽名，並保留裝置紀錄。首次使用需允許「行者光控」安裝應用程式。

更新檢查及下載會連線 GitHub，不會上傳燈具或位置資料。沒有網路仍可使用藍牙控制。下載時請保持 App 開啟；安裝前先完成燈具操作。

此 App 用於相容露營燈；實體燈具功能仍需依實際手機及機型確認。
